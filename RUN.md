# Как запустить и проверить

## Приложение (ничего ставить не нужно)

1. Скачай **`public/download/SLURP.exe`** (915 КБ) из репозитория — или прямо с сайта, кнопка «Скачать».
2. Положи в любую папку и запусти двойным кликом.
3. Windows покажет «Неизвестный издатель» (файл не подписан платным сертификатом):
   **Подробнее → Выполнить в любом случае**.
4. Откроется приложение в браузере: харнесс, настройки, визард.

Не Windows? Возьми **`public/download/SLURP.html`** — тот же интерфейс одним файлом,
открывается в любом браузере.

## Что потыкать

- В харнессе нажми подсказку «Harden the auth flow» — пойдёт прогон: план, инструменты, диффы, тесты, итог.
- Настройки → General → автономность `Ask`: при следующем прогоне появится подтверждение записи.
- Настройки → Appearance: акцент, плотность, размеры шрифтов меняются на лету.
- ⌘K / Ctrl+K в харнессе — палитра команд. `/` в поле ввода — слэш-команды.
- Ключ провайдера в Настройках включает живой режим (реальный API).

## Разработка из исходников

Нужен Node.js 18+ (только для этого пути):

```bash
npm install
npm run dev        # http://localhost:5173
```

Пересобрать сборки после правок:

```bash
npm run build:app  # → public/download/SLURP.html, SLURP.exe, SHA256.txt
```

## Частые проблемы

| Симптом | Что делать |
| --- | --- |
| «не является внутренней или внешней командой» | Ты в `cmd.exe`, а команды были для PowerShell/Bash. Для запуска приложения терминал вообще не нужен — просто открой .exe |
| SmartScreen блокирует .exe | «Подробнее» → «Выполнить в любом случае». Это отсутствие платной подписи, не вирус; исходник запускатора — `native/launcher.c` |
| Браузер не открылся после запуска .exe | Открой вручную `%TEMP%\SLURP-*.html`, он там |
| `npm install` падает с EPERM | Не запускай от администратора, не держи проект в `C:\Program Files` |
