SLURP 0.9.4
===========

1. Открой SLURP.exe (он лежит прямо здесь, рядом с этим файлом).
2. Windows покажет «Неизвестный издатель» — это потому что файл не подписан
   платным сертификатом. Нажми «Подробнее» → «Выполнить в любом случае».
3. Откроется приложение в браузере. Дальше — визард настройки.

Ничего устанавливать не нужно. Node.js, npm, интернет и права администратора
не требуются: всё приложение внутри одного файла.


Не Windows?
-----------
Открой public/download/SLURP.html в любом браузере — это тот же интерфейс
одним файлом.


Запустить сайт из исходников (нужен Node.js 18+)
------------------------------------------------
  npm install
  npm run dev        → http://localhost:5173


Что внутри приложения
---------------------
Харнесс (план → инструменты → диффы → тесты → итог), настройки (модели, персона,
ключи провайдеров, права инструментов, плагины, тема) и визард первого запуска.

Пока нет доступа к реальным файлам на диске: правки и тесты симулированы,
чтобы можно было оценить интерфейс и логику.
