SLURP 0.9.4 — приложение для Windows
====================================

Это отдельное десктоп-приложение на C# / .NET 8 / WPF. Оно открывает твою
папку с проектом, читает и правит настоящие файлы, запускает сборку и тесты.
Никакого браузера и никакой веб-обёртки: обычное окно программы.

В этой папке лежат ИСХОДНИКИ приложения. Чтобы получить SLURP.exe:

  1. Двойной клик по BUILD-WINDOWS.bat.
     - если .NET SDK 8 не установлен, скрипт поставит его через winget;
     - затем выполнит dotnet publish -c Release -r win-x64;
  2. через 1–3 минуты рядом появится SLURP.exe и сразу откроется;
  3. дальше запускай именно SLURP.exe — сборка больше не нужна.

Почему не готовый exe в архиве: WPF-приложение компилируется только с
Windows-таргетингом, а хост, на котором собирался сайт, — Linux без .NET SDK.
Поэтому вместо нерабочего файла с расширением .exe здесь лежит сборка в один
клик. После сборки exe полностью автономен: .NET внутри, Node.js не нужен.

Сборка вручную (если не хочешь bat):

  cd desktop\Slurp.Desktop
  dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
  :: результат: bin\Release\net8.0-windows\win-x64\publish\SLURP.exe


Первый запуск
-------------
1. Выбери модель в шапке (Claude, GPT, DeepSeek, Gemini, Kimi, Qwen, Mistral,
   OpenRouter или локальный Ollama / LM Studio).
2. Настройки → Провайдеры и ключи: вставь ключ нужного провайдера.
   Ключ шифруется Windows DPAPI и лежит в %APPDATA%\SLURP\settings.json.
3. Выбери рабочую папку (Ctrl+O). Агент работает только внутри неё.
4. Напиши задачу и нажми Ctrl+Enter.

Режимы автономности (переключаются в шапке):
  Ask  — спрашивает перед каждой записью файла и командой shell;
  Auto — сам правит файлы, спрашивает только перед shell;
  Yolo — не спрашивает ничего.

Esc — остановить агента.


Сайт
----
  npm install
  npm run dev     → http://localhost:5173

Пересобрать архив для скачивания:
  npm run build:app        → public/download/SLURP-Windows.zip
  npm run build:win        → public/download/SLURP.exe (нужен .NET SDK 8)
