# SLURP — the agentic coding environment

> Talk to your repo. Ship the thing.

SLURP — это харнесс для вайбкодинга в духе OpenCode / DeepSeek harness: локальный агент,
который читает репозиторий, пишет план, правит файлы, гоняет тесты и показывает диффы.
Модель — любая: облачная (Claude, GPT-5, Gemini, DeepSeek, Kimi, Qwen, Grok, Mistral,
OpenRouter) или локальная (Ollama, LM Studio), вплоть до полного офлайна.

В репозитории — **сайт с загрузкой приложения, каталог моделей, документация по тюнингу
и рабочий веб-демо харнесса** (три экрана приложения: прогон агента, настройки, визард
первого запуска).

---

## Что внутри

| Маршрут       | Что это                                                                                                 |
| ------------- | ------------------------------------------------------------------------------------------------------- |
| `/`           | Лендинг: hero с живым мокапом сессии, бенто-фичи, каталог 15 моделей с фильтрами, блок тюнинга, плагины, скачивание, FAQ |
| `/download`   | Страница загрузки: переключатель ОС, SHA-256, инструкции по установке, проверка подписи, changelog       |
| `/app`        | **Харнесс**: прогон агента (план → tool calls → диффы → тесты → итог), composer с `/`-командами, ⌘K-палитра, правая панель Run/Tools/Files |
| `/settings`   | Полная настройка: модели, персона, ключи провайдеров, права инструментов, плагины, тема, приватность    |
| `/setup`      | Визард первого запуска из 8 шагов: провайдер → ключ → модели → персона → автономность → вид → плагины → итог |

Всё состояние (модель, персона, автономность, плагины, тема, ключи) живёт в `localStorage`
и реально влияет на поведение демо: автономность `ask` включает подтверждение записи,
`test`-тумблер убирает прогон тестов, план отключается тумблером `plan`, акцент перекрашивает
интерфейс, размеры шрифтов меняются ползунками.

### Демо-режим и живой режим

- **Демо (по умолчанию).** `src/lib/agent.ts` — детерминированный движок прогона: стримит
  «рассуждение», строит план, эмитит tool-calls, диффы с подсветкой, вывод тестов, карточку
  итога со статистикой и стоимостью. Запрос классифицируется по смыслу (auth / dashboard /
  api / payments / generic) — разные задачи дают разные планы и диффы.
- **Живой режим.** Вставь ключ провайдера в `/settings → Providers & keys` — появится тумблер
  `live`. Запросы пойдут в реальный API (`src/lib/llm.ts`: SSE-стриминг для
  OpenAI-совместимых и Anthropic Messages API, системный промпт собирается из персоны,
  кастомных правил и настроек автономности).

> Важно честно: это фронтенд-продукт. Бинарники на странице загрузки — интерфейс (ссылки
> ведут на заглушки), а файловые инструменты в демо симулированы. Следующий шаг — обернуть
> `src/lib/agent.ts` в Tauri/Electron и подключить реальные `read_file` / `apply_patch` /
> `run_command` (архитектура к этому готова, см. «Дальше»).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc --noEmit + vite build
npm run preview
```

Стек: React 18 + TypeScript + Vite, react-router, lucide-react, self-hosted variable-шрифты
(Inter, Space Grotesk, JetBrains Mono). Ноль UI-китов — вся дизайн-система своя:
`src/styles/base.css` (токены, примитивы), `site.css` (лендинг), `app.css` (приложение).

## Карта кода

```
src/
  lib/
    models.ts     каталог провайдеров и моделей (цены, контекст, теги, оценки)
    plugins.ts    реестр 12 плагинов с пермишенами
    store.tsx     единый store настроек + персоны + акценты, применяет CSS-переменные
    agent.ts      движок прогона агента (план, инструменты, диффы, тесты, итог)
    llm.ts        реальный стриминг к OpenAI-совместимым и Anthropic API
  components/     Brand, ui (Switch/Seg/Range/Modal/Reveal), Thread (рендер ленты),
                  Pickers (модель, ⌘K-палитра, персоны, акценты)
  pages/          Landing, Download, Harness, Settings, Onboarding
  styles/         base.css, site.css, app.css
```

## Дизайн

Тёмная «тихая роскошь» с кислотным лаймом: зерно на плёнке, сетка-фон, стеклянные панели,
мягкие свечения, моноширинные подписи-оверлайны, диффы как главный визуальный объект.
Акцент переключается на лету (6 цветов через CSS-переменные), плотность и размеры шрифтов —
часть настроек, анимации отключаемы и уважают `prefers-reduced-motion`.
